# Manifestes de données

Les manifestes décrivent les exemples sans versionner les enregistrements. Un
jeu vocal devrait inclure au minimum le chemin relatif de l'audio, le code de
langue, la transcription de référence, la convention orthographique, le locuteur
anonymisé et le split (`train`, `validation` ou `test`). N'inclure aucune donnée
personnelle directement identifiable.
