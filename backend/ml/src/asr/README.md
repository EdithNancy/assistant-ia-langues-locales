# Reconnaissance vocale (ASR/STT)

Placer ici les outils réutilisables de préparation, d'entraînement et
d'évaluation du modèle de transcription. Les prototypes interactifs existants
restent dans `../../prototypes/speech/` tant qu'ils ne sont pas remplacés par
une implémentation de service. Chaque transcription de référence doit suivre
la convention orthographique validée pour sa langue.
